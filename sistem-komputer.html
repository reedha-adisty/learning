Ringkasan Materi

Sistem komputer adalah kumpulan perangkat keras, perangkat lunak, dan pengguna yang bekerja bersama untuk menerima data, mengolahnya, menyimpan, lalu menghasilkan informasi.

Input

Perangkat yang digunakan untuk memasukkan data atau instruksi ke dalam komputer.

Contoh Perangkat Input:

  • Keyboard - mengetik teks
  • Mouse - menggerakkan kursor
  • Scanner - mendigitalkan dokumen
  • Mikrofon - merekam suara
  • Kamera - menangkap gambar/video

Process

CPU (Central Processing Unit) membaca dan mengeksekusi instruksi untuk mengolah data menjadi informasi yang berguna.

Alur Pemrosesan:

  • Fetch - mengambil instruksi
  • Decode - mengartikan instruksi
  • Execute - menjalankan operasi
  • Store - menyimpan hasil

Storage

Penyimpanan data secara permanen dalam media fisik untuk akses jangka panjang.

Jenis Penyimpanan:

  • SSD - cepat, tahan lama
  • HDD - kapasitas besar, lebih murah
  • Flashdisk - portabel, mudah dibawa
  • Cloud - akses dari mana saja

Output

Perangkat yang menampilkan hasil pemrosesan data kepada pengguna dalam bentuk visual atau audio.

Contoh Perangkat Output:

  • Monitor - menampilkan gambar/video
  • Printer - mencetak dokumen
  • Speaker - menghasilkan suara
  • Proyektor - menampilkan ke layar besar
