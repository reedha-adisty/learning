01

Perintah ping

📡 Definisi & Fungsi

ping adalah perintah paling dasar dalam diagnostik jaringan. Perintah ini bekerja dengan mengirimkan paket ICMP Echo Request ke alamat tujuan, kemudian menunggu balasan berupa ICMP Echo Reply. Dari respons tersebut, kita dapat mengetahui apakah sebuah host dapat dijangkau (reachable) dan seberapa cepat koneksi tersebut bekerja.

Dalam konteks keamanan siber, ping sering digunakan pada fase reconnaissance (pengintaian) untuk memverifikasi keberadaan host di jaringan sebelum melakukan pengujian lebih lanjut.

ICMP Latency Check Network Reachability Reconnaissance
terminal — ping smkn1salam.sch.id 
root@asesmen:/home/salam# ping smkn1salam.sch.id
PING smkn1salam.sch.id (2606:4700:3037::6815:1208) 56 data bytes
64 bytes from 2606:4700:3037::6815:1208: icmp_seq=1  ttl=56 time=53.5 ms
64 bytes from 2606:4700:3037::6815:1208: icmp_seq=2  ttl=56 time=53.5 ms
64 bytes from 2606:4700:3037::6815:1208: icmp_seq=3  ttl=56 time=53.3 ms
64 bytes from 2606:4700:3037::6815:1208: icmp_seq=4  ttl=56 time=53.5 ms
64 bytes from 2606:4700:3037::6815:1208: icmp_seq=5  ttl=56 time=53.6 ms
64 bytes from 2606:4700:3037::6815:1208: icmp_seq=6  ttl=56 time=53.1 ms
64 bytes from 2606:4700:3037::6815:1208: icmp_seq=13 ttl=56 time=53.1 ms
💡

Analisis Output: Nilai time menunjukkan latensi dalam milidetik (ms). Rata-rata ~53 ms menunjukkan koneksi stabil ke server. Nilai ttl=56 mengindikasikan paket melewati sekitar 8 router sebelum mencapai tujuan (TTL awal biasanya 64). IPv6 address 2606:4700:3037::6815:1208 menandakan server menggunakan Cloudflare CDN.

⚙️ Parameter Penting

ParameterFungsiContoh
-c [n]Menentukan jumlah paket yang dikirimping -c 5 google.com
-i [detik]Interval antar paketping -i 2 google.com
-s [byte]Ukuran paket yang dikirimping -s 1024 google.com
-t [ttl]Atur nilai Time To Liveping -t 64 google.com
-4 / -6Paksa protokol IPv4 atau IPv6ping -4 google.com
02

Perintah traceroute

🗺️ Definisi & Fungsi

traceroute (atau tracert di Windows) adalah perintah yang digunakan untuk memetakan seluruh jalur yang dilalui paket data dari komputer sumber menuju alamat tujuan. Cara kerjanya adalah dengan mengirimkan paket dengan nilai TTL (Time to Live) yang dimulai dari 1 dan terus bertambah, sehingga setiap router di sepanjang jalur akan merespons dan mengidentifikasi dirinya.

Dalam keamanan siber, traceroute membantu mengidentifikasi infrastruktur jaringan, menemukan titik kemacetan (bottleneck), serta mendeteksi adanya perangkat yang tidak dikenal di jalur koneksi yang bisa mengindikasikan adanya serangan Man-in-the-Middle.

TTL Manipulation Route Mapping Network Topology MitM Detection
terminal — traceroute elearning.smkn1salam.sch.id 
root@asesmen:/home/salam# traceroute elearning.smkn1salam.sch.id

Analisis Output: Terdapat 10 hop dari sumber ke tujuan. Hop 1 adalah gateway lokal. Hop 2–4 melewati infrastruktur Telin (Telekomunikasi Indonesia International) di Yogyakarta dan Jakarta. Hop 8–10 menunjukkan server berada di jaringan Cloudflare (172.67.x.x dan 172.69.x.x), mengkonfirmasi penggunaan Cloudflare sebagai CDN dan proteksi DDoS.

03

Perintah nslookup

🔍 Definisi & Fungsi

nslookup (Name Server Lookup) adalah alat untuk melakukan kueri terhadap server DNS (Domain Name System) guna mendapatkan informasi terkait domain atau alamat IP. DNS berfungsi seperti buku telepon internet — mengubah nama domain yang mudah diingat manusia (seperti google.com) menjadi alamat IP yang dimengerti komputer.

Dari perspektif keamanan, nslookup digunakan untuk mengidentifikasi infrastruktur server, mendeteksi konfigurasi DNS yang salah, melakukan DNS enumeration, dan memverifikasi apakah suatu domain menggunakan perlindungan seperti Cloudflare.

DNS Query Domain Resolution IP Lookup DNS Enumeration
terminal — nslookup google.com 
root@asesmen:/home/salam# nslookup google.com
Server:         127.0.0.53
Address:        127.0.0.53#53

Non-authoritative answer:
google.com    canonical name = forcesafesearch.google.com.
Name:   forcesafesearch.google.com
Address: 216.239.38.120
Name:   forcesafesearch.google.com
Address: 2001:4860:4802:32::78
💡

Analisis Output: Server DNS lokal di 127.0.0.53 (systemd-resolved) merespons kueri. Tertulis "Non-authoritative answer" karena jawaban berasal dari cache, bukan server DNS otoritatif. Terdapat CNAME record yang mengarahkan google.com ke forcesafesearch.google.com — ini umum terjadi di jaringan sekolah yang menerapkan SafeSearch paksa. Dua alamat IP (IPv4 dan IPv6) dikembalikan, menunjukkan server mendukung dual-stack.

📋 Tipe Record DNS yang Perlu Diketahui

RecordKeteranganContoh Query
AMemetakan domain ke IPv4nslookup -type=A google.com
AAAAMemetakan domain ke IPv6nslookup -type=AAAA google.com
MXServer email untuk domainnslookup -type=MX google.com
CNAMEAlias ke domain lainnslookup -type=CNAME www.google.com
NSName server otoritatifnslookup -type=NS google.com
PTRReverse lookup IP → domainnslookup 8.8.8.8

Perintah netstat

📊 Definisi & Fungsi

netstat (Network Statistics) adalah perintah yang menampilkan daftar lengkap koneksi jaringan aktif, port yang sedang didengarkan (listening), tabel routing, dan statistik antarmuka jaringan. Perintah ini sangat berguna untuk memantau keadaan jaringan secara real-time.

Dalam konteks keamanan siber, netstat menjadi alat penting untuk mendeteksi koneksi mencurigakan, memantau port yang tidak seharusnya terbuka, dan mengidentifikasi kemungkinan adanya malware yang sedang melakukan komunikasi ke server luar (backdoor atau command-and-control).

Port Monitoring Connection State Backdoor Detection Network Audit
terminal — netstat -a (ringkasan) 
root@asesmen:/home/salam# netstat -a
Active Internet connections (servers and established)
Proto  Recv-Q Send-Q  Local Address          Foreign Address        State
tcp         0      0  0.0.0.0:8146          0.0.0.0:*             LISTEN
tcp         0      0  0.0.0.0:38922         0.0.0.0:*             LISTEN
tcp         0      0  0.0.0.0:ftp           0.0.0.0:*             LISTEN
tcp         0      0  0.0.0.0:mysql         0.0.0.0:*             LISTEN
tcp         0    256  *:nstest.te.net.id:8146 140.213.160.80:56058  ESTABLISHED

💡

Analisis Output: Server ini menjalankan banyak layanan: FTP (port 21), HTTP (80), HTTPS (443), dan MySQL (3306) terbuka di semua antarmuka — ini berpotensi menjadi risiko keamanan jika tidak dibatasi firewall. Koneksi ESTABLISHED ke IP 140.213.160.80 menunjukkan ada sesi aktif yang perlu diverifikasi legitimasinya. Port non-standar 8146 dan 38922 perlu diinvestigasi lebih lanjut.

Wireshark – Analisis Paket Jaringan

🦈 Definisi & Fungsi

Wireshark adalah network packet analyzer berbasis GUI yang paling banyak digunakan di dunia, baik untuk keperluan profesional maupun akademis. Wireshark bekerja dengan menempatkan antarmuka jaringan dalam mode promiscuous, memungkinkan ia menangkap seluruh paket data yang melintas melalui jaringan — bahkan paket yang tidak ditujukan untuk komputer tersebut.

Dalam keamanan siber, Wireshark digunakan untuk melakukan traffic analysis, mendeteksi protokol tidak terenkripsi yang membocorkan data sensitif, menganalisis serangan jaringan secara forensik, serta mendebug komunikasi antara aplikasi dan server.

Packet Capture Deep Packet Inspection Traffic Analysis Network Forensics

🖥️ Tampilan Wireshark – Live Capture (Wi-Fi)

Gambar: Tangkapan layar Wireshark sedang merekam paket secara langsung dari antarmuka Wi-Fi. Terlihat campuran protokol QUIC, ICMP, UDP, dan TCP. Panel bawah menampilkan detail layer per paket beserta data hex mentah.

🔬 Cara Kerja Wireshark

Proses kerja Wireshark dapat dibagi menjadi tiga tahap utama:

TahapProsesKeterangan
1. Capture Penangkapan Paket Wireshark menangkap paket dari antarmuka jaringan yang dipilih (Wi-Fi, Ethernet, Loopback, dll.) secara real-time
2. Filter Penyaringan Data Gunakan display filter (misal: tcp.port == 80 atau ip.addr == 192.168.1.1) untuk fokus pada paket tertentu
3. Analyze Analisis Mendalam Setiap paket dapat dibedah layer demi layer: Ethernet → IP → TCP/UDP → Application Protocol (HTTP, DNS, FTP, dll.)
⚠️

Catatan Etika & Hukum: Menggunakan Wireshark untuk menangkap lalu lintas jaringan orang lain tanpa izin adalah illegal di sebagian besar negara dan melanggar undang-undang ITE di Indonesia. Gunakan hanya pada jaringan yang Anda miliki atau dengan izin eksplisit dari pemilik jaringan.

📝 Filter Wireshark yang Berguna

FilterFungsi
httpTampilkan hanya paket HTTP
dnsTampilkan hanya paket DNS
tcp.port == 443Tampilkan traffic HTTPS
ip.src == 192.168.1.1Paket dari IP tertentu
icmpHanya paket ICMP (ping)
tcp.flags.syn == 1Deteksi paket SYN (koneksi baru/port scan)

Netcat – Uji Koneksi Port Langsung

🔌 Definisi & Fungsi

Netcat (dikenal juga sebagai "Swiss Army Knife of Networking") adalah utilitas jaringan serbaguna yang dapat membaca dan menulis data melalui koneksi jaringan menggunakan protokol TCP atau UDP. Dengan netcat, pengguna dapat membuat server sederhana, menghubungkan dua terminal melalui jaringan, atau menguji apakah suatu port terbuka tanpa memerlukan aplikasi khusus.

Dalam pengujian keamanan, netcat digunakan untuk port scanning sederhana, membuat reverse shell (dalam simulasi penetration testing yang sah), mentransfer file, dan memverifikasi konektivitas ke layanan tertentu.

TCP/UDP Port Testing Reverse Shell Sim File Transfer
terminal — netcat uji koneksi port 80 ke google.com 
root@asesmen:/home/salam# nc -zv google.com 80
Connection to google.com (2001:4860:4802:32::78) 80 port [tcp/http] succeeded!
💡

Analisis Output: Flag -z membuat netcat hanya menguji koneksi tanpa mengirim data (zero-I/O mode), sementara -v mengaktifkan output verbose. Pesan "succeeded!" mengkonfirmasi bahwa port 80 (HTTP) di google.com terbuka dan dapat dijangkau. Koneksi dilakukan via IPv6 ke alamat Cloudflare — konsisten dengan hasil nslookup sebelumnya.

⚙️ Penggunaan Umum Netcat

PerintahFungsi
nc -zv host portUji apakah port terbuka
nc -zv host 20-80Scan range port 20 hingga 80
nc -l -p 1234Buat server TCP di port 1234
nc host 1234Hubungkan sebagai client ke port 1234
nc host 1234 < file.txtKirim file ke host melalui jaringan
nc -u host 5000Koneksi menggunakan protokol UDP

Praktikum ini memperkenalkan enam perintah dan alat fundamental dalam ekosistem Linux yang menjadi fondasi pengujian keamanan jaringan (network security testing). Keenam alat tersebut saling melengkapi dan membentuk alur kerja diagnostik yang komprehensif:
