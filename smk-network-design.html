// Network Segmentation

Segmentasi Jaringan — VLAN Design

Konsep Segmentasi
Jaringan dibagi menjadi 6 VLAN berdasarkan peran pengguna dan area. Setiap VLAN memiliki subnet tersendiri, sehingga broadcast domain terisolasi. Traffic antar VLAN hanya diizinkan melalui router/firewall dengan kebijakan ACL yang ketat.
VLAN ID
Nama
Subnet / Range

GW: .10.1 | Host: .10.2–.10.254 🖥 30–40 PC siswa praktikum. Internet terbatas waktu. Tidak bisa akses printer guru & shared folder internal.
20 Lab Komp 2 192.168.20.0/24
GW: .20.1 | Host: .20.2–.20.254 🖥 30–40 PC siswa praktikum. Konfigurasi identik VLAN 10. Terisolasi dari VLAN 10 (tidak saling ganggu).
30 Guru 192.168.30.0/24
GW: .30.1 | Host: .30.2–.30.254 👨‍🏫 PC & laptop guru, printer guru, shared folder pedagogis. Dapat akses server sekolah dengan autentikasi.

GW: .40.1 | Host: .40.2–.40.10 👔 Kepala Sekolah + Wakil. Akses penuh monitoring jaringan. Dapat melihat laporan semua VLAN.

// Inter-Building Routing

Routing Antar Gedung

Arsitektur Routing
Core Switch berfungsi sebagai Router-on-a-Stick dengan sub-interface untuk setiap VLAN (Inter-VLAN Routing). Koneksi antar gedung menggunakan trunk link fiber/copper berkecepatan Gigabit. Semua traffic melewati Firewall sebelum ke internet.
Core Router — Inter-VLAN
! Sub-interface per VLAN interface Gi0/0.10 encapsulation dot1Q 10 ip address 192.168.10.1 255.255.255.0 interface Gi0/0.20 encapsulation dot1Q 20 ip address 192.168.20.1 255.255.255.0 interface Gi0/0.30 encapsulation dot1Q 30 ip address 192.168.30.1 255.255.255.0 interface Gi0/0.40 encapsulation dot1Q 40 ip address 192.168.40.1 255.255.255.0 interface Gi0/0.50 encapsulation dot1Q 50 ip address 192.168.50.1 255.255.255.0 interface Gi0/0.60 encapsulation dot1Q 60 ip address 192.168.60.1 255.255.255.0 interface Gi0/0.99 encapsulation dot1Q 99 ip address 192.168.99.1 255.255.255.0 ! Default route ke firewall ip route 0.0.0.0 0.0.0.0 10.0.0.1

QoS — Bandwidth Management

🎓
Guru & Manajemen
Prioritas DSCP EF (Expedited Forwarding). Bandwidth guaranteed 10Mbps. Tidak terdampak saat praktikum berjalan.
🖥
Siswa Lab (VLAN 10/20)
Bandwidth pool bersama 20Mbps per lab. Per-user limit 1Mbps. Jadwal akses sesuai jam praktikum.
🪑
Tamu (VLAN 60)
Bandwidth shared 5Mbps seluruh VLAN tamu. Prioritas terendah. Captive portal dengan login.
🖧
Server Internal
Traffic server diprioritaskan di jaringan lokal. Update/backup dijadwalkan malam hari saat traffic rendah.

ACL — Access Control List

Contoh Implementasi ACL (Cisco IOS)
! === ACL: Blokir Siswa akses ke Guru & Server === ip access-list extended ACL_SISWA_OUT ! Izinkan akses ke web server sekolah (port 80,443) permit tcp 192.168.10.0 0.0.0.255 192.168.99.10 0.0.0.0 eq 80 permit tcp 192.168.10.0 0.0.0.255 192.168.99.10 0.0.0.0 eq 443 ! Izinkan DNS internal permit udp 192.168.10.0 0.0.0.255 192.168.99.10 0.0.0.0 eq 53 ! Blokir akses ke semua VLAN internal deny ip 192.168.10.0 0.0.0.255 192.168.30.0 0.0.0.255 deny ip 192.168.10.0 0.0.0.255 192.168.40.0 0.0.0.255 deny ip 192.168.10.0 0.0.0.255 192.168.50.0 0.0.0.255 deny ip 192.168.10.0 0.0.0.255 192.168.99.0 0.0.0.255 ! Izinkan ke internet permit ip 192.168.10.0 0.0.0.255 any ! === ACL: Total Blokir Tamu ke internal === ip access-list extended ACL_TAMU_OUT deny ip 192.168.60.0 0.0.0.255 192.168.0.0 0.0.255.255 permit ip 192.168.60.0 0.0.0.255 any ! Terapkan ACL ke sub-interface VLAN 10 interface Gi0/0.10 ip access-group ACL_SISWA_OUT out interface Gi0/0.60 ip access-group ACL_TAMU_OUT out

// Network Security

Pengamanan Akses Jaringan Internal

🛡️
Firewall / UTM
Deploy Firewall (pfSense/Palo Alto) sebagai gerbang utama internet. Fitur: stateful inspection, IDS/IPS, web filtering, antivirus gateway, dan VPN termination.
Stateful IDS/IPS Web Filter
🔐
802.1X Port Authentication
Setiap port switch memerlukan autentikasi sebelum mendapat akses VLAN. Perangkat tidak terdaftar otomatis masuk VLAN Tamu (Guest VLAN). RADIUS server sebagai backend autentikasi.
RADIUS EAP-TLS Auto VLAN
📡
WiFi Security — WPA3
SSID terpisah per segmen: SSID_GURU (WPA3-Enterprise, VLAN 30), SSID_SISWA (WPA3-SAE, VLAN 10/20), SSID_TAMU (Open+Captive Portal, VLAN 60). Isolasi antar client WiFi aktif.
WPA3 Client Isolation Captive Portal
🔒
VLAN Hopping Prevention
Nonaktifkan DTP (Dynamic Trunking Protocol) di semua access port. Native VLAN diubah ke VLAN tidak terpakai (VLAN 999). Port tidak terpakai dimatikan dan dimasukkan ke VLAN dead.
No DTP Shutdown unused Native VLAN 999
🧩
Port Security
Batasi jumlah MAC address per port (max 2). Jika MAC baru terdeteksi, port otomatis shutdown (violation mode restrict). Sticky MAC untuk binding perangkat tetap di lab.
Sticky MAC Auto Shutdown Max 2 MAC
📊
SNMP Monitoring & Syslog
Semua perangkat kirim log ke Syslog server terpusat (VLAN 99). SNMP v3 (terenkripsi) untuk monitoring performa. Dashboard Grafana/Zabbix real-time untuk IT Admin.
SNMPv3 Syslog Grafana
🕵️
DHCP Snooping & DAI
DHCP Snooping mencegah rogue DHCP server di jaringan. Dynamic ARP Inspection (DAI) mencegah ARP spoofing/poisoning antar host dalam satu VLAN.
DHCP Snoop DAI Anti-Spoof
🔑
MFA & Password Policy
IT Admin wajib Multi-Factor Authentication untuk akses management. Password minimal 12 karakter, rotasi 90 hari. SSH v2 only; Telnet dinonaktifkan sepenuhnya di semua perangkat.
MFA SSHv2 only No Telnet
💾
Backup & Recovery
Konfigurasi perangkat di-backup otomatis setiap malam ke server backup. Data server sekolah: incremental backup harian, full backup mingguan. RTO target: 4 jam, RPO: 24 jam.
Auto Backup RTO 4h RPO 24h
